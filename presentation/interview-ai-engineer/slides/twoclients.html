Two clients that share a design and deliberately not a codebase

Concern Desktop Android
Message intake Headless browser, scrollable history Notification listener — forward-only, long messages arrive truncated

Approval Card with an attachment, reaction approves Impossible — no API to message an arbitrary chat; replaced with a local notification

Why not share the core

The browser automation cannot run on Android at all, and the calendar path loses its entire auth layer. The "shared core" would have been everything except the two parts that differ — an abstraction whose implementations have nothing in common.

Truncation, handled honestly

Long announcements — the ones that actually contain events — arrive cut off. The body is marked, and the extractor is instructed to return an empty date rather than guess the rest. Inventing a time from half a sentence is how a wrong event reaches a calendar.

Same pipeline shape · same approve-before-publish guarantee · same dedup layering

Short slide; the point is a judgement call rather than a technique. The obvious move when you port something is to extract a shared core. I did not, and I want to be able to defend that. The browser automation cannot run on Android under any circumstances, and the calendar path loses its whole auth layer because the account is already on the device. So the shared core would have been everything except the two things that actually differ — an interface with two implementations that have nothing in common. What I shared instead was the design: same pipeline shape, same approve-before-publish guarantee, same dedup layering, expressed in each platform's idioms. The right-hand box is the honest-engineering bit. On mobile, long messages arrive truncated — and the long ones are exactly the ones carrying events. Rather than let the model complete the sentence, the body is marked and the extractor is told to return an empty date. I would rather ask the parent than invent a time. That is the same instinct as fail-open earlier: when the system does not know, it says so.
