Ports, not clients

The AI layer is four task-shaped ports — extract events, classify relevance, judge duplicates, embed — not one callLLM(string). A port that returns text forces every caller to re-derive meaning from it; that is where 180 lines of JSON repair had grown.

The boundary is enforced, not agreed

An architecture test fails the build if anything outside the adapter and graph layers imports @langchain/*. The framework cannot leak into the domain because a human forgot at review time.
